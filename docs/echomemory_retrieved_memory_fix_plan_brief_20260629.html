EchoMemory 检索记忆修复方案

面向 Memory-System-Eval-Harness 的精简版修改清单。

1. 目标

  • 正式 QA 默认使用 vikingboat_lite
  • 正式 QA 默认开启 qa_memory_injection
  • 避免生成 selected=[] 的空 recall 文件
  • 导入不完整时禁止启动正式 QA

2. 必改文件

文件 修改点
memory/services/task_orchestrator.py
  • echomemory_qa + locomo 时，空值或 one_shot 强制归一到 vikingboat_lite
  • qa_memory_injection 默认强制为 true
  • vikingboat_tool_loop 默认开启
memory/plugins/echomemory/tasks.py
  • QA 命令构造默认 prompt_mode 从 one_shot 改成 vikingboat_lite
  • 非法值 fallback 不要回落到 one_shot
  • qa_memory_injection 默认保持 true
memory/task_specs.py
  • Retry failed QA 默认 prompt_mode 不再使用 one_shot
  • --qa-memory-injection 默认开启
scripts/retry_failed_echomemory_qa.py
  • CLI 默认 --prompt-mode 改成 vikingboat_lite
  • 如果收到 one_shot，构造命令时归一到 vikingboat_lite

3. 结合当前代码的修改点

3.1 task_orchestrator 入口归一化

/Users/chx/locomo-eval-web/memory/services/task_orchestrator.py
if kind == "echomemory_qa" and (dataset_format in {"", "locomo"}):
    prompt_mode = str(normalized.get("prompt_mode") or "").strip().lower()
    if prompt_mode in {"", "vikingboat_lite", "vikingboat_compat"}:
        normalized["vikingboat_tool_loop"] = True
    if str(normalized.get("qa_memory_injection") or "").strip().lower() in {"", "0", "false", "no", "off"}:
        normalized["qa_memory_injection"] = True
    if prompt_mode in {"", "one_shot"}:
        normalized["prompt_mode"] = "vikingboat_lite"
  • 这段逻辑应该保留，作为所有 EchoMemory LoCoMo QA 的统一入口默认值。
  • 目的：不让空 payload 或旧配置把任务带回 one_shot + no injection。

3.2 QA 命令构造默认值

/Users/chx/locomo-eval-web/memory/plugins/echomemory/tasks.py
当前：
prompt_mode = str(payload.get("prompt_mode") or payload.get("qa_prompt_mode") or "one_shot").strip() or "one_shot"
if prompt_mode not in {"one_shot", "vikingboat_lite", "vikingboat_compat"}:
    prompt_mode = "one_shot"
vikingboat_tool_loop = bool_value(payload.get("vikingboat_tool_loop"), False)

建议改成：
prompt_mode = str(payload.get("prompt_mode") or payload.get("qa_prompt_mode") or "vikingboat_lite").strip() or "vikingboat_lite"
if prompt_mode not in {"one_shot", "vikingboat_lite", "vikingboat_compat"}:
    prompt_mode = "vikingboat_lite"
vikingboat_tool_loop = bool_value(payload.get("vikingboat_tool_loop"), prompt_mode in {"vikingboat_lite", "vikingboat_compat"})
  • 这里是最终下发脚本命令的地方，必须和 orchestrator 保持一致。
  • 同样的修改也建议同步到 build_echomemory_generic_qa_command()。

7. 验收标准

summary.json:
qa_memory_injection_enabled = true
prompt_mode = vikingboat_lite
retrieval_ok_count > 0

qNNN.recall.json:
selected_count > 0
selected[*].uri / score / memory_type / preview 存在

judge_summary.json:
uses_retrieved_memory = true

这三项满足，就说明不是“空 recall 结果”。
