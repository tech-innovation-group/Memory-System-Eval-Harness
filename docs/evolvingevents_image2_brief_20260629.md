# EvolvingEvents 评测 - Image-2 设计 Brief

## 目标

为本地 AI 记忆 / 事件时间线评测平台设计一个桌面端 Web 工作台页面，页面名称为：

`EvolvingEvents 评测`

这不是营销页，不是聊天首页，不是 BI 大屏，而是一个内部 benchmark console。

整体风格参考 `LoCoMo 评测` 的克制感、工程秩序和浅色工作台气质，但不要完全照搬。  
`EvolvingEvents` 应该更轻、更简洁、更少模块堆叠。

用户打开页面后，要能快速完成这条工作流：

`配置数据 -> 校验数据集 -> 选择题目 / 时间线 -> 开始测试 -> 观察运行状态 -> 查看最近结果`

请不要为了好看增加新功能。只保留这个工作流所需模块。

---

## 整体视觉方向

- 桌面端工作台，尺寸感接近 `1440 x 1024`
- 浅暖灰背景：`#F7F5F0`
- 白色面板：`#FFFFFF`
- 细边框：`#E5DED2`
- 主文字：`#111827`
- 次级文字：`#6B7280`
- 弱文字：`#9CA3AF`
- 主蓝：`#2563EB`
- 成功绿：`#16A34A`
- 警告橙：`#D97706`
- 错误红：`#DC2626`
- 圆角统一 `8px`
- 模块间距 `16px`
- 按钮高度 `36px`
- 输入框 / Select 高度 `40px`
- 表格行高约 `44px`
- 不要大阴影，最多极弱阴影
- 不要渐变
- 不要蓝紫 AI 风格
- 不要 Hero
- 不要插画
- 不要 KPI 大卡
- 不要 workflow stepper
- 不要 card-inside-card
- 不要大面积空白

整体气质更接近：

- Linear
- LangSmith
- OpenAI Console
- Vercel Dashboard

关键词：

`专业 / 克制 / 工程感 / 高可扫描性 / 单任务工作流 / 轻量 benchmark console`

## 页面信息架构

页面只保留下面这些结构：

```text
Header
Status Bar
Main Grid
  Left 68%
    数据配置
    运行控制
    题目与时间线预览
  Right 32%
    数据集摘要
    运行配置
    运行状态
    最近结果
Bottom Log
```

不要再出现：

- 大标题 Hero 区
- 多步骤流程条
- KPI 卡片横排
- 历史任务大卡
- 启动前检查大卡
- 重复解释文案

---

## 1. 顶部 Header

这是一个紧凑 Header，不是 Hero。

高度控制在 `56px ~ 64px`。

左侧内容：

- 标题：`EvolvingEvents 评测`
- 一句简短说明：`事件时间线问答 · 本地 Benchmark Console`

右侧操作按钮：

- 使用示例数据
- 校验数据集
- 开始测试
- 查看结果

按钮要求：

- `开始测试` 使用蓝色主按钮
- 其他使用白底细边框次级按钮
- 所有按钮高度一致，`36px`
- 按钮使用 `图标 + 文字`
- 图标统一用 Lucide 风格线性图标
- 图标尺寸 `16px`
- 按钮间距 `8px`

图标建议：

- 使用示例数据：`Database`
- 校验数据集：`ShieldCheck`
- 开始测试：`Play`
- 查看结果：`FileBarChart`

---

## 2. Header 下方 Status Bar

Header 下方是一整行紧凑状态带，不做 KPI 卡片。

包含 4 个状态块：

1. 当前数据集
2. 当前范围
3. 当前进度
4. 运行状态

表现方式：

- 整体高度约 `60px`
- 白底
- 细边框
- 圆角 `8px`
- 4 个状态块统一高度
- 每项结构为：`图标 + 小标签 + 当前值`
- 不要大数字
- 不要彩色背景
- 不要 Dashboard 风格

示例内容：

- 当前数据集：`EvolvingEvents · sample.jsonl`
- 当前范围：`20 questions · sample mode`
- 当前进度：`0 / 20`
- 运行状态：`Idle / Running / Completed / Failed`

进度表达：

- 使用细进度条
- 进度条要稳重，不要粗笨

运行状态表达：

- 小 pill 或小圆点状态标签
- 不要大块彩色状态区

图标建议：

- 当前数据集：`Database`
- 当前范围：`Target`
- 当前进度：`Gauge`
- 运行状态：`Activity`

---

## 3. 主体两栏布局

整体为两栏：

- 左侧主区约 `68%`
- 右侧摘要栏约 `32%`

两列顶部严格对齐。

模块之间 gap 统一 `16px`。

不要让右侧变成大而空的说明栏。  
右侧应该是紧凑摘要，不抢主流程。

---

## 4. 左侧主区

左侧按行排列 3 个模块。

### 模块 A：数据配置

模块标题：

- 图标：`SlidersHorizontal`
- 标题：`数据配置`

只保留必要字段：

第一行：

- 数据路径 input
- 选择文件按钮

第二行：

- 测试题数 input
- 模式 select
- split / subset select（如果页面已有这个概念就保留，否则不要硬加）

设计要求：

- 表单控件高度统一 `40px`
- Label 使用小号辅助文本
- 输入内容单行显示
- 路径文字允许优雅截断
- 不要因为长路径把页面撑乱
- 使用清晰的 grid 对齐，不要自由堆叠

不要放：

- KPI
- 大段说明文字
- 很重的空状态卡片

---

### 模块 B：运行控制

模块标题：

- 图标：`PlayCircle`
- 标题：`运行控制`

内容只保留紧凑操作条：

- 开始测试
- 正式 20
- 全量
- 加载题目
- 清空选择

设计要求：

- 不做大卡片
- 不做二级说明区
- 只做一行紧凑按钮组
- `开始测试` 为主按钮
- 其他为次级按钮
- 所有按钮统一高度 `36px`
- 使用 `图标 + 文字`

图标建议：

- 开始测试：`Play`
- 正式 20：`ListChecks`
- 全量：`Rows3`
- 加载题目：`RefreshCw`
- 清空选择：`X`

---

### 模块 C：题目与时间线预览

这是左侧最重要的区域，也是页面主视觉中心。

模块标题：

- 图标：`Timeline`
- 标题：`题目与时间线预览`

右侧可带轻量工具：

- 搜索框
- 类型 / 时间范围筛选（仅当已有对应字段时保留）

主体建议：

- 固定高度，约 `360px`
- 内部滚动
- 表格或高密度列表形式
- 这是页面最大模块，优先保证它可读、可选、可连续扫描

建议列结构：

- 选择框
- question id
- 时间线摘要
- 问题
- event time / 时间字段
- 状态

设计要求：

- 行高稳定
- 列头清楚
- 文本不溢出
- 表格不要过于花哨
- 尽量像工程工作台的预览区，而不是业务后台表格

---

## 5. 右侧摘要栏

右侧做成 4 个上下排列的小面板，结构统一。

1. 数据集摘要
2. 运行配置
3. 运行状态
4. 最近结果

每个面板都应采用：

- 小标题 + 图标
- 左标签、右值 的紧凑信息布局

避免：

- 空旷大卡片
- 长段描述
- 类 BI 看板排版

### 数据集摘要

展示示例：

- 文件名
- 事件条数
- 问题数
- 时间线范围

### 运行配置

展示示例：

- 模式
- 题量
- 当前过滤条件
- 选择状态

### 运行状态

展示示例：

- Idle / Running / Completed / Failed
- 当前进度
- 开始时间
- 耗时 / ETA

### 最近结果

展示示例：

- 最近结果文件
- 结果目录
- 最新准确率 / 状态摘要
- 报告入口

最近结果面板应像一个轻量 artifact summary，  
而不是文件管理器。

---

## 6. 底部日志区

页面底部独占一整行日志区。

要求：

- 固定高度约 `200px ~ 220px`
- 深灰蓝背景，建议 `#161B22`
- 边框 `#334155`
- 字体浅灰
- 风格接近工程控制台的 console

空状态：

- 居中显示：`暂无日志输出`

不要：

- 纯黑背景
- 过高日志面板
- 大面积空黑块

---

## 图标语言

统一使用同一套线性图标语言，风格克制。

要求：

- 按钮图标 `16px`
- 模块标题图标 `16px`
- 状态图标 `14px`
- 图标默认继承文字颜色
- 只在成功 / 警告 / 错误状态使用语义色
- 禁止彩色装饰图标
- 禁止 Emoji

---

## 最终设计意图

这个页面最重要的不是“好看得像产品首页”，而是：

1. 一眼知道先做什么
2. 操作区和状态区分工清楚
3. 预览区成为视觉中心
4. 右侧只做摘要，不抢主流程
5. 整体更像专业 AI Benchmark Console，而不是一堆后台卡片拼接

请把这个页面设计成：

`更轻的 LoCoMo 同系列页面`

而不是：

- Dashboard
- 管理后台
- 营销页
- 炫技型 AI 工具首页
