# 飞书应用创建与凭证获取指南

## 一、创建飞书自建应用

1. 打开 [飞书开放平台](https://open.feishu.cn)，登录企业账号
2. 点击「开发者后台」->「创建企业自建应用」
3. 填写应用名称（如「评测结果上报」）和描述
4. 创建完成后，在「凭证与基础信息」页面获取：
   - **App ID**（格式如 `cli_a5xxxxx`）
   - **App Secret**（点击显示后复制）

## 二、配置应用权限

1. 进入应用管理页面，左侧菜单选择「权限管理」
2. 搜索并开启以下权限：
   - `bitable:app` — 多维表格读写
3. 点击「批量开通」确认

## 三、发布应用

1. 左侧菜单选择「版本管理与发布」
2. 创建版本并提交审核
3. 管理员审核通过后应用生效

## 四、创建多维表格并授权

1. 在飞书中新建一个多维表格（多维表格入口：飞书左侧导航 -> 工作台 -> 多维表格）
2. 从多维表格的 URL 中获取凭证：

   ```
   https://<tenant>.feishu.cn/base/<app_token>/table/<table_id>
                                    ^^^^^^^^^^          ^^^^^^^^^
                                    App Token           Table ID
   ```

3. 点击多维表格右上角「...」->「添加协作者」
4. 搜索并添加你的自建应用，赋予「可编辑」权限

## 五、初始化表格列结构

表格创建后，对 AI agent 说「初始化飞书评测结果表格」：

1. AI agent 会向用户收集 App ID、App Secret、App Token、Table ID
2. AI agent 读取 `references/table_fields.json`，逐个用 curl 调飞书 API 创建 52 列
3. 创建完成后即可开始上传评测结果

## 六、凭证说明

| 凭证 | 获取位置 | 说明 |
|---|---|---|
| App ID | 开放平台 -> 凭证与基础信息 | 应用唯一标识 |
| App Secret | 开放平台 -> 凭证与基础信息 | 应用密钥，不可泄露 |
| App Token | 多维表格 URL 中 `/base/` 后的部分 | 多维表格唯一标识 |
| Table ID | 多维表格 URL 中 `/table/` 后的部分 | 表格标识 |

> 所有凭证仅在 skill 运行时由用户交互式提供，不落盘、不写入文件、不进入环境变量。
