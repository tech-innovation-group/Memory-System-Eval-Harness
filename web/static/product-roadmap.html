Public UI Contract

MemoryBench Product Roadmap

当前公开入口遵循 web/ui_contract.json。本页保留为交付边界中的公开静态页面，用于说明当前发布口径和后续前端收敛方向。

OpenViking + EchoMemory Split Frontend Assets Legacy Mirror Required

当前口径

  • 公开 UI 入口以 index.html + app-state.js + app-core.js + app-format.js + app.js + styles.css 为准。
  • web/static 与顶层 static 必须保持镜像一致，避免运行时与交付边界漂移。
  • LoCoMo 记忆导入页的后续优化应继续以减少耦合、减少重复刷新和减少镜像漂移为优先目标。

后续收敛方向

  • 继续把 LoCoMo 导入页 helper 从 app.js 中抽离，避免导入页逻辑与其他评测页互相污染。
  • 把双份前端镜像的一致性纳入测试和预检，避免“改一份、另一份反作用”。
  • 历史实验 HTML 仍然保留在 web/static/generated-reports/，但不属于公开入口。
