Backends

左侧侧边栏目标形态

左侧导航固定为十个任务入口：侧边栏只放用户任务，不放脚本名、实验页和内部工具。

1

对话

MemoryBench Agent 人工测试台：主动对话、relevant memory、context trace、手动保存记忆。

2

LoCoMo评测

四块主流程：记忆导入、问答测试、判分、查看报告。

3

LongMemEval评测

长记忆评测入口；运行 MemoryBench memory-QA，官方原指标单独标识。

4

EvolvingEvents评测

事件演化和时间线检索评测入口；MemoryBench event-memory QA 与官方原 benchmark 指标分开展示。

5

HotpotQA评测

多跳 QA 评测入口；answer EM/F1 与官方 supporting-fact/joint 指标分开展示。

6

proAgentBench评测

Agent 任务评测入口；MemoryBench task-memory QA 先形成可复现报告，官方 proactive 指标另接 runner。

7

Tau2-bench评测

工具任务评测入口；MemoryBench tool-task QA 可跑，官方 Tau2 Pass^k/reward 另行标注。

8

chenmo评测

长期记忆推理评测入口，统一到同一报告 schema。

9

系统配置

当前账户的后端、workspace、模型、预检、隔离和交付门禁。

MemoryBench Agent 可比标准

Agent 的目标不是靠额外兜底把分数抬高，而是复现 VikingBoat 关键上下文工程，让准确率差异能归因到记忆系统、检索和模型。

模块保留能力正式分数禁止项验收
检索Top-K、score、uri、abstract、source session。跨账户读旧记忆、手工拼 evidence。每题可展开 relevant memory。
上下文system prompt、question、retrieved memory、context trace。raw conversation fallback、archive fallback、隐式全文读取。报告保存 context source 和 fallback 开关。
回答Answer LLM 只基于当前 context 作答。模型异常算 wrong、待判分算 0 分。CSV 分开记录 unknown、model_error、pending。
人工对话手动发送、查看证据、手动保存记忆。自动污染长期记忆。保存后展示 workspace、session、memory 路径。

LoCoMo 第一条做穿

LoCoMo 页面是产品可信度的第一张脸，也是唯一当前要求双后端可复现的正式主链路，固定只露出四块：记忆导入、问答测试、判分、查看报告。

Import

记忆导入

校验 LoCoMo JSON，选择单个、多个或全部 conv；展示 expected/submitted/committed、session、memory root、日志失败数。

QA

问答测试

展示题目文本、gold、类别解释；支持单题、多题、时间题、上一轮错题和全量，并查看 relevant memory。

Judge

判分

显示判分进度、待判分数量、补跑入口和失败原因；待判分不显示为 0%。

Report

查看报告

HTML 包含配置快照、准确率、token、耗时、evidence、context、失败归因、run diff。

24 小时迭代节奏

0-4h界面减法

固定十个侧边栏入口；清理旧实验入口、冗余文案和混乱卡片；首页只展示当前账户、后端、workspace、运行任务和下一步。

验收：新用户 1 分钟知道从哪开始。
4-8hLoCoMo 主链路

把数据集校验和完整性检查归入“记忆导入”，主流程固定为记忆导入、问答测试、判分、查看报告；所有错误都有下一步动作。

验收：conv-30 单题到报告可复现。
8-12hAgent 对话台

重做对话界面：输入区更大，证据和 context 固定在侧栏，保存记忆后展示路径与完整性检查。

验收：人工测试不污染历史记忆。
12-16h报告和结果中心

结果中心默认只显示当前交付范围 run；报告第一屏展示分数、配置、失败桶、可重跑建议。

验收：不再被旧历史实验误导。
16-20h后端契约

OpenViking 基线和 EchoMemory 接入共用 adapter contract；系统配置支持当前账户独立切换和隔离验证。

验收：两条链路都能跑 LoCoMo 单题到报告闭环。
20-24h开源质感

完善 README、脱敏 demo report、issue 模板、preflight、浏览器截图和一键核验计划。

验收：外部测试者不问人也能跑。

Agent Alignment Gate

Backend Matrix

Scope

正式分数边界

LoCoMo 是当前双后端正式主链路；其他数据集先输出可复现的 MemoryBench memory-QA，并把官方原 benchmark 指标单独标注。

验收门禁

Boundary后端边界一致

/api/backends 只返回 OpenViking 与 EchoMemory；公开 README 和方案页不出现旧后端路线。

Navigation侧边栏固定 10 个入口

web/ui_contract.json、DOM 和交付审计一致。

LoCoMo单题到报告必须跑通

从记忆导入、问答测试、判分到查看报告，所有产物路径可复制。

Isolation账户隔离可证明

当前 account 的 workspace 和 storage root 不与其他账户共享。

Security无密钥外泄

所有 key 只显示是否配置，不回显内容；外发包不包含 runs/workspace。
