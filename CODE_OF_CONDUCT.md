# Code of Conduct

We want this project to be useful and welcoming for memory-system researchers,
agent builders, benchmark maintainers, and external testers.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent while staying precise about evidence and reproducibility.
- Keep benchmark discussions grounded in configuration, data, traces, and reports.
- Redact secrets, private data, and private model outputs before sharing.
- Help newcomers run the smoke test before asking them to debug full evaluations.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language
- Publishing another person's secrets, API keys, private paths, or private datasets
- Misrepresenting benchmark results by hiding configuration, evidence, or Judge status
- Pressuring contributors to share private workspaces or provider credentials

## Enforcement

Maintainers may edit, hide, or remove issues, discussions, or pull requests that
violate this code of conduct or expose sensitive data. Repeated or severe
violations may lead to blocked participation.
