EchoMemory Nano Ablation

This is a toy experiment for understanding the architectural direction, not a paper-grade benchmark result. It answers two narrower questions: 1) does nano v2 preserve event time better than nano v1; 2) on the same v2 memory graph, is planned retrieval better than flat lexical retrieval for evidence selection.

Scenario

  • 2023-01-20 · Jon lost his job as a banker on 2023-01-19 and decided to start a dance studio.
  • 2023-01-28 · Jon visited Paris on 2023-01-28 and said it was cool.
  • 2023-02-01 · Gina visited Rome on 2023-01-30 after her design interview.
  • 2023-02-03 · Jon's ideal dance studio is by the water, with natural light and Marley flooring.

Part A. Extraction sanity

Here the gold signal is the real event date in the sentence, not the logging date. This mirrors a real long-memory failure mode: confusing event_time with created_at.

Part B. Retrieval routing ablation

Both settings use the same v2 graph nodes. The only difference is whether retrieval first plans which layers to prioritize.

temporal_q1

Query: When did Jon lose his job?

Expected: top1 is event and contains 2023-01-19

Time-sensitive query should prefer event evidence and surface the true event date, not the record date.
