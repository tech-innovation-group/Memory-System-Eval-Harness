EchoMemory Multimodal Nano Ablation

This is a toy multimodal ablation for the CVPR-oriented branch. It compares text-only retrieval against multimodal retrieval on the same memory graph and focuses on one narrow question: when does image evidence become necessary instead of merely helpful?

Interpretation

The core expected pattern is not that multimodal always beats text-only on every query. Instead:

  • for screenshot-specific questions, multimodal retrieval should surface image_evidence nodes
  • for OCR-only answers, text-only retrieval should fail while multimodal retrieval succeeds
  • for style or preference questions, multimodal memory should complement text rather than replace it
