EchoMemory Nano: Type-Aware Second Pass Ablation

这个实验比较三种 retrieval policy： one_pass、 graph-only second pass、 type-aware second pass。 核心问题不是“多做一次补检会不会更好”，而是 当 evidence contract 缺的是不同类型的证据时，系统能不能补对 reader。

cases=5 one_pass contract ok=1 graph-only contract ok=3 type-aware contract ok=5

结果概览

one pass

1 / 5

只看 primary reader，最容易停在结构不完整的证据上。

graph-only second pass

3 / 5

能修 tree-first 时间题，但在 graph-primary 的 ordered-relation 题上会卡住。

type-aware second pass

5 / 5

根据 missing_layers 选择 tree / atom / graph，更接近真正的 contract-driven policy。
