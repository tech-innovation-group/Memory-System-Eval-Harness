EchoMemory Nano: Graph-first Ablation

这个实验专门回答一个方法问题：为什么 EchoMemory 值得把 temporal / relational / visual query 交给 graph-first planner。 我们比较三种检索模式： lexical baseline（只看 block/fact 文本匹配）、 graph-first（按 query intent 优先 event / image_evidence）、 graph-path（在 graph-first 基础上沿边补 path evidence）。

lexical baseline1/4
graph-first3/4
graph-path4/4
最重要结论Graph is not decoration

Interpretation

如果结果如预期，说明两件事： 第一，时间题和视觉题不是“多检索点文本”就够了，而是要让 event、image_evidence 直接成为主证据入口。 第二，只把图节点召回出来还不够，沿边拿到 path evidence 会比孤立节点更接近真实系统要做的事。
