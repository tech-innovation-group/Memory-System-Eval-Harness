EchoMemory Visual Memory Eval Harness

This is a small but more structured evaluation harness for the multimodal nano line. It is still a toy evaluation, but it is more systematic than a single smoke or a single ablation table.

Interpretation

  • OCR-only questions should fail under text-only retrieval and succeed under multimodal retrieval.
  • Visual-anchor questions should make image_evidence the top retrieval path.
  • Hybrid-support questions should keep textual answers while surfacing visual evidence as support.
