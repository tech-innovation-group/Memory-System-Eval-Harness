最重要结论

  • 视觉 query 这条线已经比较像成熟 planner 行为。
  • temporal / relational query 仍然是下一步最值得改的地方。 现在它们更像“更深检索”，还不是“显式 graph-first routing”。
  • 所以论文里最诚实的说法应该是：EchoMemory 已经有 real-code planner skeleton，但 planner maturity 在不同 query family 上是不均衡的。
